# Ապրանքի դասակարգում և միավորային դրոշմավորում

| Դաշտ | Ի՞նչ է նույնականացնում | Օգտագործում խանութում |
|---|---|---|
| Շտրիխկոդ | Ապրանքացանկում որոնվող ապրանքը կամ փաթեթավորումը | Սկանով ընտրել ապրանքի քարտը |
| GTIN | Առևտրային ապրանքային միավորը՝ տվյալ տեսակի և փաթեթավորման համար | Համադրել միավորի դրոշմում կարդացված GTIN-ը ապրանքի քարտին |
| ԱՏԳ ԱԱ ծածկագիր | Արտաքին տնտեսական գործունեության ապրանքային անվանացանկով ապրանքի դասը | Պահպանել ստուգված դասակարգումը ապրանքի քարտում |
| Data Matrix դրոշմ | Կոնկրետ ֆիզիկական միավորը | Գրանցել նույն միավորի մուտքը, վաճառքը կամ վերադարձը |

Դրոշմավորման ազգային օպերատորը նկարագրում է Data Matrix մակնշումը միավորի փաթեթավորման վրա։ Հսկիչ նշանների կիրառությունը կախված է ապրանքախմբից, ուժի մեջ մտնելու ամսաթվից և անցումային պայմաններից։ Օրինակ՝ ՊԵԿ-ը բացատրում է ԱՏԳ ԱԱ 2208 խմբի որոշ ապրանքների համար սահմանված կարգավորումը։ Յուրաքանչյուր ապրանքի կարգավիճակը որոշելիս հաշվի առեք տվյալ ապրանքի բնութագիրը, գործարքի ամսաթիվը և գործող իրավական ակտը։ [E-Mark](https://www.emark.am/hy) · [ՀՀ ՊԵԿ](https://www.src.am/am/getNews/1038)

### Գործարքները և սահմանները

- **Մատակարարում և մուտք։** Որոշ ապրանքախմբերի մատակարարման ժամանակ հաշվարկային փաստաթղթում ներառվում են հսկիչ նշանների և քանակի տվյալները՝ համապատասխան ժամկետից։ ERP-ի տեղային պահեստային մուտքից առանձին պետք է ստուգել կիրառելի մատակարարման փաստաթուղթը և նշանների համադրումը։ [Կարգը և ժամկետները, կետեր 2–4](https://www.arlis.am/en/acts/232081)
- **Մանրածախ վաճառք։** ՀԴՄ կիրառության կանոններում նախատեսված է դրոշմավորված ապրանքի նշանի տվյալների փոխանցումը հարկային մարմնի միասնական շտեմարան։ Կանոնները նաև առանձնացնում են ապրանքի ԱՏԳ ԱԱ քառանիշ ծածկագրի համապատասխանությունը։ Ապրանքի քարտի լրիվ տասնանիշ դասակարգումը և ՀԴՄ-ի քառանիշ դաշտը տարբեր նպատակներ ունեն։ [ՀՀ կառավարության N 1976-Ն որոշում, հավելված 3](https://www.arlis.am/ru/acts/210833)
- **Վերադարձ։** Տեղային վերադարձը կապվում է տվյալ վաճառքի և տվյալ միավորի հետ։ Ֆիսկալ վերադարձի ձևակերպումն ունի սեփական ընթացակարգն ու վերադարձի կտրոնը։ [ՀՀ կառավարության N 1976-Ն որոշում](https://www.arlis.am/hy/acts/211533)

### Փորձնական տարբերակի կիրառությունը

Փորձնական գործառույթը նախատեսված է տեղային հաշվառման համար։ Ադմինը պահպանում է դասակարգումը և սահմանում միավորային դրոշմավորման ռեժիմը։ Սկանավորված ծածկագրի ձևաչափը, կրկնությունները և ընթացիկ պահեստային վիճակը ստուգվում են տեղում։ Կառավարության սահմանած համակարգն ապահովում է նաև միավորների նույնականացումն ու շրջանառության փուլերի գրանցումը։ [ՀՀ կառավարության որոշում՝ համակարգի գործառույթներ](https://arlis.am/hy/acts/181851)

Արտադրական ներդրման ընդունման համար առանձին ստուգման ենթակա են կոնկրետ ապրանքախմբերի կոդերի կառուցվածքները, օպերատորի համակարգում դրոշմի իսկությունն ու կարգավիճակը, կիրառելի մատակարարման փաստաթղթերը, ՀԴՄ վաճառքի և վերադարձի տվյալների փոխանցումը, ինչպես նաև մերժված կամ անորոշ պատասխանի հաշտեցումը։ Այս փուլում պաշտոնական համակարգերից ընդունման հաստատում չի ստացվում։
